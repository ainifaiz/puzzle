# 🌟 Misi Anak Sederhana

Permainan pembelajaran interaktif **Pendidikan Moral Tahun 1** bertema **Nilai Kesederhanaan**.

## Standard Pembelajaran
- **SP 13.1** – Memberi contoh sikap tidak keterlaluan dalam kehidupan seharian.
- **SP 13.4** – Menyatakan perasaan apabila bersikap sederhana dalam kehidupan seharian.
- **SP 13.5** – Mengamalkan perlakuan sederhana dalam kehidupan seharian.

## 4 Misi
1. 💧 **Selamatkan Air** – tutup pili dan pilih tindakan yang tidak membazir.
2. 💡 **Pejuang Jimat Elektrik** – tutup peralatan yang tidak digunakan dan jawab situasi KBAT.
3. 🍚 **Pinggan Saya Secukupnya** – pilih 3–4 makanan, bezakan pinggan sederhana, dan pilih perasaan.
4. 💰 **Tabung Bijak** – urus RM5 berdasarkan keperluan dan simpan baki.

## Ciri
- HTML5 + CSS3 + Vanilla JavaScript
- Mesra tablet/iPad dan skrin sentuh
- Teks dan butang besar
- Sistem 4 bintang
- Text-to-speech Bahasa Melayu jika disokong pelayar
- Kemajuan disimpan dalam `sessionStorage`
- Tiada backend, login, database atau API berbayar
- Animasi menghormati `prefers-reduced-motion`
